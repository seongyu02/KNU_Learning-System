# ALL 캠퍼스

강남대학교 이캠퍼스에 흩어진 **과제 마감과 강의 시청 기간**을 한 화면에서 확인하는 학생용 웹앱입니다. 네트워크서비스 수업의 개인 과제인 ‘마감 계기판’에서 출발해, 여러 학생이 각자의 일정을 관리할 수 있도록 확장했습니다.

## 주요 기능

- **이캠퍼스 로그인** — 별도 회원가입이나 달력 주소 입력 없이 내 일정을 불러옵니다.
- **마감 대시보드** — 과제와 강의를 구분하고, 마감까지 남은 시간과 월별 일정을 확인합니다.
- **일정 동기화** — 로그인할 때 일정을 가져오고 이후 자동으로 갱신합니다. 필요할 때 **지금 동기화**를 눌러 바로 갱신할 수 있습니다.
- **개인 일정 관리** — 완료를 표시하고, 이캠퍼스에 없는 일정을 직접 추가할 수 있습니다.

이캠퍼스 달력에 등록된 일정이 자동으로 표시됩니다. 과제 제출 여부와 강의 시청 진도는 직접 확인해야 합니다.

## 동작 방식

Cloudflare Worker가 로그인할 때 이캠퍼스에서 개인 iCal 주소를 받아 암호화한 뒤 D1에 저장합니다. 이캠퍼스 비밀번호는 로그인 요청 처리에만 사용하며 저장하지 않습니다. 이후 동기화는 암호화해 둔 달력 주소로 처리하고, 일정과 완료 상태는 계정별로 관리합니다.

ALL 캠퍼스는 강남대학교의 공식 서비스가 아닙니다. 웹앱에서 **내 데이터 삭제**를 선택하면 저장된 일정과 계정 데이터가 삭제됩니다.

## 학교 계정 없이 확인하기

저장소 루트에서 아래 명령을 실행합니다. 예시 일정으로 파서와 화면 빌드를 확인하고, 모의 이캠퍼스와 로컬 데이터베이스로 로그인 및 데이터 접근 제어를 검증할 수 있습니다. Python 3과 Node.js 22.5 이상이 필요합니다.

```bash
node deploy/test.mjs "내과제/예시일정.ics"
python deploy/build.py
cd deploy
node security.test.mjs
```

로컬 웹앱 실행, Cloudflare 배포, D1 초기화와 마이그레이션 절차는 배포 문서에 있습니다. [배포 가이드](deploy/README.md)
