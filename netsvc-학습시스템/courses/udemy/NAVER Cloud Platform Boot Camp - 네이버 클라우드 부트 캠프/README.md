## 개요

NAVER Cloud Platform에서 인스턴스, 스토리지, 네트워크, 데이터베이스 등의 서비스를 사용해 클라우드 인프라를 구성하는 방법을 실습 중심으로 학습하는 과정이다.

기본적인 리눅스 사용법과 TCP/IP·서브넷(subnet) 등의 네트워크 기초 지식이 있으면 학습에 도움이 된다. 실습 후에는 과금 방지를 위해 생성한 인스턴스와 서비스를 삭제하고, 계정에는 다중 인증(2FA)을 설정하는 것이 권장된다.
